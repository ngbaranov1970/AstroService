# Астро-сервис — контекст проекта (выжимка обсуждения, июль 2026)

## Суть
B2C-сервис астрологических AI-разборов для русскоязычной аудитории: точный расчёт (натальная карта, Матрица Судьбы, восточный гороскоп) + LLM-синтез. Бесплатный базовый разбор как приманка, платные глубокие отчёты. Цель — доход. Разработка ведётся вечерами параллельно с основной работой, с помощью Claude (тариф Max).

## Ключевые решения
1. Изначальная идея «сайт с гороскопами» отвергнута: бесплатный расчёт — коммодити, SEO по главным запросам занято старыми сайтами.
2. Выбран путь B2C: бот → Mini App → платные AI-разборы.
3. Из-за деградации Telegram в РФ **целевая платформа — VK**: VK Mini App как основной фронт, сайт — платёжный и SEO-хаб. Но ядро платформо-независимое, и это не «VK-first» по срокам — см. «Порядок выхода на платформы».
4. Пользователь изучает VK Mini Apps самостоятельно (VK Bridge, проверка sign, туннель) — код обсуждаем, но с пониманием.
5. **Платформенный адаптер закладывается сразу**, чтобы второй канал не стоил переписывания: на backend — пара `(platform, external_id)` в `users` вместо `vk_id` и интерфейс `verify_launch(platform, raw) → external_id` с реализациями под VK (`sign`) и Telegram (`initData`), обе HMAC-SHA256; на фронте — модуль `platform.ts` (`getUser / share / openLink / haptic`) с двумя реализациями, остальное приложение о платформе не знает.

## Рынок (главное из исследования)
- Бесплатные калькуляторы натальных карт — коммодити: astro-seek, eso3, astrolog4you и десятки других отдают всё бесплатно.
- Платный лидер рунета — Chronos: фримиум, подписка на персональные прогнозы, платные «планы развития», тарифы для астрологов 550–10 000 ₽/мес.
- Глобальный рынок гороскоп-приложений ~$194 млн (2026), рост ~11%/год; 72%+ платных транзакций — микроплатежи и подписки; тренд — AI-разборы карт.
- Telegram-конкуренты: Natalon (Swiss Ephemeris + AI-разбор, премиум 100 ₽/мес — ценовой якорь снизу), LunaCode Astro, экосистемы ИИ-ботов (астрология/таро/хиромантия). Кейс: бот астролога Маковера — 100+ продаж в первый месяц.
- Ручной рынок ВК: исполнительницы продают совместимость за ~300 ₽ по ФИО и датам рождения, ответ через несколько часов. Это подтверждённый спрос, цена и низкий барьер доверия; продукт конкурирует с ручным трудом — автоматизация даёт мгновенность, визуал и глубину по той же цене.
- Дыры конкурентов: нет нормального визуала и личного кабинета (бот-формат), разборы «по темам» вместо цельного синтеза, Матрица Судьбы + натал + восточный редко в одном продукте.

## Платформенные ограничения (критично для стратегии)
- Telegram официально замедляется в РФ с февраля 2026, риск полной блокировки — нельзя делать единственным каналом.
- Реклама эзотерики/астрологии **запрещена в VK Ads** → трафик: посевы у админов эзотерик-пабликов напрямую, виральность (инвайт на совместимость, шеринг карточки в сторис), позже SEO сайта в Яндексе.
- Цифровые товары внутри VK Mini Apps продаются только за «голоса» с большой комиссией платформы, на iOS запрещены → **оплата всегда на сайте через ЮKassa** (вебхук разблокирует отчёт в приложении).

## Порядок выхода на платформы (решение 2026-07-27, заменяет 2026-07-25)

Порядок: **веб-стенд → Telegram-бот → VK Mini App**. Предыдущая редакция
ставила обкатку в бот первым шагом; решение изменено, причины ниже.
Целевая платформа по-прежнему VK — меняется только порядок обкатки.

### Почему обкатка начинается с веба, а не с бота

**Главное: бот не может показать два разбора рядом.** Бот — линейный диалог
один-на-один, экрана в нём нет в принципе; сравнение свелось бы к команде
`/admin`, вываливающей простыни текста в чат, и к листанию скроллом с
удержанием прочитанного в голове. А сравнение похожих карт у разных людей —
это и есть главный тест качества промпта: если DeepSeek выдаёт двум разным
людям почти одинаковый текст, значит он не привязывается к карте, а льёт
воду. Ровно это мы и должны ловить, и ловить глазами, в две колонки.

**Веб-слой неизбежен в любом случае.** Оплата всегда на внешнем сайте
(ограничение VK, см. выше) — значит FastAPI, отдающий HTML, будет написан
при любом сценарии. Стенд сейчас — это первая версия того, что уже в плане,
а не работа на выброс.

**Порог входа.** Ссылка открывается в любом браузере: ничего не ставить,
VPN не нужен. Бот требует Telegram, обхода замедления и доверия «что это за
бот вообще».

Цена решения: бот знает имя человека и умеет написать первым («как тебе
разбор?»), веб — нет. Возвращать тестера придётся личной просьбой в
мессенджере. Тестеров знают лично, поэтому это не проблема.

Бот **не отменяется**: он остаётся каналом к существующей базе подписчиков
и едет следующим шагом, после того как промпты устоятся. Побочный выигрыш —
не придётся переписывать хендлеры бота под каждую правку промпта.

### Что представляет собой стенд

Два экрана и админка на **Jinja2** (шаблонизатор, FastAPI отдаёт готовый
HTML): никакой сборки, npm и Vue — это тестовый инструмент, а не продукт.
Экраны: форма ввода → выбор города → страница разбора с оценкой 1–5.
Админка — таблица всех карт и `/admin/compare?ids=3,7`: тексты в колонках
рядом. Последнее — то, ради чего всё затевается.

Пользователь без регистрации: `platform='web'`, `external_id` — случайный
UUID в cookie на год (пара `(platform, external_id)` в `users` для этого и
заложена). Регистрации нет, как и планировалось.

### Что проверяет обкатка (не зависит от канала)

- **качество и тон текста** — главное, чего нельзя проверить самому;
- **различимость разборов** — тексты двух людей рядом в колонках; главная
  болезнь LLM-астрологии, в одиночку незаметна, платящий клиент видит сразу;
- **контроль на эффект Барнума** — чужая карта под именем тестировщика: если
  «прямо про меня», текст слишком общий, нужна опора на реальные градусы, дома
  и аспекты вместо психологической воды;
- **геокодинг на грязном вводе** («мск», «с. Ивановка», «время не помню»);
- практика полного разбора: разбивка по секциям, время генерации,
  фактическая стоимость одного отчёта в токенах — база для проверки, что
  490 ₽ вообще осмысленны. (Лимит сообщения Telegram в 4096 символов из
  этого списка уходит: в вебе его нет, но секции всё равно нужны — по ним
  проходит граница пейволла.)

Тестерам открывается **полный разбор** (флаг `is_tester`, без оплаты) —
проверяем платный продукт, а не усечённый.

Чего эта обкатка НЕ даёт: спроса и экономики. Аудитория тёплая и знакомая,
конверсия будет завышена в разы против холодного VK-посева — по ней нельзя
выставлять финальную цену и нельзя принимать решение о масштабировании.

### Что стенд в открытом интернете требует сразу

- **HTTPS и домен.** Собираем дату и место рождения — персональные данные, а
  браузер на голом IP пишет «Не защищено». Домен (~200–400 ₽/год) нужен и под
  ЮKassa, и под заявку в каталог VK, так что это ускорение, а не расход;
  сертификат берёт на себя Caddy (Let's Encrypt, три строки конфига).
  Временный костыль на пару дней — `sslip.io`.
- **Админка под HTTP Basic Auth** (логин/пароль в `.env`): без этого таблица
  с датами рождения живых людей лежит в открытом интернете.
- **Потолок расходов на DeepSeek**: форма открыта всем, значит лимит
  генераций на cookie в сутки плюс общий дневной потолок. Кеш отчётов по
  `(chart_id, type, prompt_version)` в схеме уже есть — повтор бесплатен.

Отсрочка VK имеет цену: модерация каталога занимает недели, заявку подавать
рано, параллельно с обкаткой, а не после.

## Продукт и цены MVP
- Бесплатно: расчёт карты + краткий AI-синтез + матрица + восточный знак; секции полного разбора под блюром.
- Платно: полный разбор 490 ₽, совместимость 590 ₽, комплект 890 ₽ (разовые покупки).
- v1.1 (месяц 2): подписка на ежедневные прогнозы по транзитам + рассылки через сообщения сообщества.

## Стек и архитектура
- Backend: FastAPI, SQLAlchemy 2 + Alembic, Postgres 16; расчётное ядро pyswisseph + kerykeion (SVG колеса); Матрица Судьбы — арифметика; восточный — cnlunar/lunardate; геокодинг GeoNames + timezonefinder (исторические таймзоны!).
- LLM: DeepSeek; вход — JSON «астропаспорт», кеш отчётов по (расчёт, тип, prompt_version); тон без медицины и фатализма.
- **Безопасность текста — два уровня, не один.** Расчёт на «провайдер сам отфильтрует» ошибочен: фильтр DeepSeek ловит явное («вы умрёте в 2031»), а модерацию VK и доверие убивает мягкое, которого полно в астрологическом корпусе — «слабое место — щитовидка», «склонность к депрессии», «период связан с потерей близкого», «часто встречается у людей с зависимостями». При `temperature 1.0` выход стохастический: не вылезло на двух прогонах — вылезет на двухсотом. Поэтому промпт — первая линия, **пост-фильтр в коде** (стоп-лексика: диагнозы, смерть, «обязательно случится» → регенерация или срезание абзаца) — вторая. Без неё на модерацию не идём.
- Следствие: **все генерации логируются в БД с самого начала** (текст, prompt_version, модель, temperature, usage). Тест в Telegram нужен в том числе чтобы набрать корпус реальных выходов — на нём и строится пост-фильтр.
- Frontend: Vue 3 + Vite + VK Bridge; авторизация — проверка HMAC-подписи launch params → JWT; VKUI не используется (React-only), визуал свой.
- Платежи: ЮKassa на сайте; юр. база — самозанятость (НПД: 4%/6%, лимит 2,4 млн ₽/год, совместимо с работой по найму, оформляется в «Мой налог»).
- Таблицы: users, charts, reports, orders, events (своя аналитика воронки).
- Деплой: Docker Compose на VPS; опция — VK Cloud (бонус 2 500 ₽/мес для Mini Apps); есть грантовая программа VK Dev Grants.

## План месяца (кратко, пересмотрен 2026-07-25)
- Нед. 1 (сделано): скелет проекта, расчётное ядро со сверкой 10 эталонных дат с astro-seek, геокодинг, первый сквозной прогон «дата → JSON → текст», конфиг и слой БД.
- Нед. 2: модели и первая миграция → `services/charts.py` + `services/reports.py` (кеш, лимиты, лог генераций) → полный разбор посекционно → раздача в закрытой тест-группе Telegram. Фоном, потому что бюрократия идёт своим темпом: самозанятость, заявка ЮKassa, заявка в каталог VK.
- Нед. 3: правки промптов по живому фидбеку, пост-фильтр текста на собранном корпусе; Mini App — auth через адаптер, онбординг, экран карты, события аналитики.
- Нед. 4: оплата (сайт + ЮKassa + вебхук), пейволл, лендинг; посев в 2–3 пабликах (3–5 тыс. ₽), дашборд метрик.

Важно: бот дёргает сервисы **напрямую**, а не через HTTP API — `app/api/*`
не нужен до Mini App, иначе FastAPI поднимается ради одного тестового бота.

## Метрики решения (конец месяца)
Вход → карта ≥ 60%; карта → пейволл ≥ 30%; пейволл → оплата 2–5% (холодный); окупаемость посева первой покупкой ≥ 30%. По результатам: масштабировать / чинить онбординг / чинить пейволл.

Считать только по **холодному** трафику. Тест на своей ТГ-базе даёт качество текста и работоспособность цепочки, но не конверсию: знакомые люди искажают воронку в обе стороны.
